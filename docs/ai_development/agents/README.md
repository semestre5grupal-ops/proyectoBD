# Available Agents

This README is the index of all AI agent definitions available in this folder. It provides a quick inventory of each agent's role, a short description of its specialization, and the exact file where its full instructions are defined.

| Name | Description | File location |
|---|---|---|
| **architect-reviewer** | Reviews code changes for architectural integrity, MVC boundaries, database isolation, and SOLID compliance. | [`./architect-reviewer.md`](./architect-reviewer.md) |
| **frontend-architect** | Designs modular folder structures, event listeners routing, and service layer integration for the ERP client. | [`./architect.md`](./architect.md) |
| **engineer** | Implements code changes in the frontend controllers, views, and services, as well as backend Node.js APIs. | [`./engineer.md`](./engineer.md) |
