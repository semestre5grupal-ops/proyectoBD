# Language Guidelines Index

This folder contains language-specific development guidelines for contributors and AI agents.

---

## Active Languages

- **JavaScript (ES6+)**: Coding standards for frontend DOM controllers, view templates, and asynchronous fetch/axios service modules.
- **Node.js (Express)**: Coding standards for backend configurations, MVC controllers, schemas, route maps, and middleware functions.

---

## Agent Usage Guidelines

1. Read this index to understand active language profiles.
2. Load only relevant language documents during feature implementation.
3. Prefer ES6+ features (e.g., arrow functions, destructuring, promises, async/await).
4. If no language guidance exists for a requested stack, ask for direction before inventing standards.
